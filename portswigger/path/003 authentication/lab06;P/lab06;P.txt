Lab06: Username enumeration via account lock
PRACTITIONER

PRINCIPLE
If a usernames is valid and a set of login attempts on this username fial, the users account should experience a lockdown

METHOD
For this, we intercept a login attempt and set the attack type to cluster bomb

For the password payload we set the payload type to Null payloads and give a payload count of 5 so each username is iterated over 5 times at least and the username payload use the provided usernames

Now notice each returns an error message missing parameter ?

Sort the results by content length, one such login attempt should return an error message "You have made too many incorrect login attempts"

Note this username and change the attack type to single list, now attempt logins with the username found above and the provided passwords

Once attempts have been made, notice one of the responses come without any error message ?

With this credentials obtained, wait 1 minute for the lock to reset then attempt a login with the found creds to solve the lab
